# VSS CDN 怎样传远景

LOD 是远处地形的简化数据。一列 LOD 对应地图上的一个区块坐标，覆盖该位置的垂直地形。VSS 决定向玩家提供哪些列并编码，Voxy 在客户端绘制远景。VSS CDN 负责把编码好的数据送到客户端。

## 两条连接各做什么

```text
游戏连接   玩家 ⇄ Velocity ⇄ 当前后端的 VSS
          用于地形请求、更新通知，以及指向数据的小消息

下载连接   玩家 → CDN → Velocity bridge → 对应后端
          只有 CDN 未命中时，才从 bridge 回源
```

Velocity 里的 bridge 有两个职责。它通过玩家现有的游戏连接下发 CDN 地址，通过独立 HTTP 端口接收 CDN 回源请求。bridge 再用自己的 TCP 连接访问各个后端。main 和 survive 可以共用这套入口，bridge 根据对象 URL 里的后端 UUID 找到正确的服。

## 一列地形怎样到达玩家

1. **决定走哪条链路。** 玩家进入后端或切换维度时，客户端通过游戏连接同时取得 bridge 的 CDN 地址和当前后端的身份。协商完成前，VSS 照常收发。若 Velocity 看到玩家来源是 `192.168.*.*`，且开着默认的局域网直连选项，就让此会话走原生 VSS。玩家用公网域名登录也一样，判断依据是来源 IP。
2. **按原有流程准备数据。** 玩家靠近一个区域后，VSS 仍按自己的请求和缓存规则处理。如果已有 LOD，就复用已有数据。缺少 LOD 时，能否读取区块、何时生成和何时编码都由 VSS 与 Minecraft 决定。CDN 只能提供已经生成并发布的地形。
3. **先给一个小地址，再下载数据。** 后端把 VSS 已编码的字节保存为发布对象，通过游戏连接告诉客户端对象的版本和位置。客户端拿到引用后，从 CDN 下载，最多同时处理 8 个 HTTP 下载。
4. **CDN 有缓存就直接返回。** 冷对象首次访问时，CDN 向 bridge 回源，bridge 从正确的后端取数据。只要对应缓存节点还保有这一版本，后续访问就能复用，减少源站上传。不同节点可能各自回源。
5. **交回 VSS。** 客户端验证响应后，把数据交给原生 VSS 解码和入库。已有通过原生校验的同版本缓存时，可以跳过 HTTP 下载。同一 URL 已在下载时，新引用会复用正在进行的请求。

## 地形改了，CDN 会看到新版吗

会。假设同一坐标的旧版地址以 `/42.bin` 结尾。玩家改动地形后，VSS 按原有规则通知客户端更新。后端收到新的编码结果并确认字节改变时，会分配新的版本号，客户端改用新地址，例如 `/43.bin`。

旧地址始终代表旧字节，源站清理后也可以返回 `410`。新地址会按正常流程缓存，无需刷新旧地址。末尾是持久化的递增整数，允许跳号。相同坐标、编码格式、大小和字节都相同时，继续用原地址。完整 URL 还包含后端、世界、发布代和维度，用这些字段防止不同后端或世界的对象混在一起。

## 切服、断网和本地缓存

| 情况 | 实际行为 |
| --- | --- |
| 从 main 切到 survive 或切换维度 | 取消旧会话的 HTTP 工作，重新协商 CDN。迟到的旧响应无法写进当前会话。世界识别和缓存键仍由原生 VSS/Voxy 决定。 |
| CDN 临时返回 503 | 最多再试两次，持续失败则退回原生 VSS，重新请求没完成的列。 |
| HTTP 超时、响应校验失败或对象已过期 | 当前会话停止 CDN 下载并回退。重连、切服或切维度时可以重新协商。 |
| 同一原生缓存键下，从 CDN 切到直连或再切回来 | 两条链路共用已有的 VSS/Voxy 数据。能复用的地形继续复用。是否跨不同入服地址共享，由原生 VSS 的规则决定。 |
| 玩家未装 CDN 模组，或未完成 CDN 协商 | 继续通过原生 VSS 传送地形。 |

## 能省什么，部署时要留什么空间

- **带宽与速度。** 热门区域被多人访问时，CDN 命中可省去重复回源，同时绕开游戏连接传输大包的限制。冷对象仍消耗源站上传。VSS 的请求窗口、生成、读取和客户端入库速度依然会限制远景加载速度。原生 VSS 带宽设置继续限制直连，HTTP 流量需在 HTTP 或网络侧单独管理。
- **磁盘。** Minecraft 世界存档、原生 VSS LOD 缓存、HTTP 发布文件是三份用途不同的数据。后端会额外保存已编码字节的发布副本，默认上限 64 GiB。
- **全图准备。** 常规发布由玩家请求触发。可以提前用原生 VSS 准备支持的地形，再用实际已发布的 URL 给热门区域预热。仓库当前没有全图离线导出、OSS 推送或厂商 CDN 预热工具。
